# EmpireVanilla

**EmpireVanilla** — сервер выживания от команды EmpireProjekt. Здесь обычный майнкрафт, каким его сделали разработчики. Без кастомных предметов, без магазинов, без валюты.

Мы только убрали мелочи, которые бесят. Двойные двери открываются вместе. Грядки не топчутся. В сундуках структур лут есть для каждого. Всё остальное — чистая ваниль.

## Что здесь особенного

Коротко. Подробности — на других страницах вики.

- **Лут для каждого.** В сундуках структур у каждого игрока свой лут. Даже если сундук до тебя открыли десять раз.
- **Мир не заканчивается.** Сейфы в trial chambers открываются снова. В Незере стоят шпили с сокровищами.
- **События.** Иногда на сервере случается что-то необычное. Двойная добыча, тёмная ночь, охота за кладами.
- **Меньше рутины.** Урожай собирается правой кнопкой. Компостер принимает весь стак. Поезда из вагонеток.
- **Безопасный мир.** Отдельный мир для проверенных игроков. Без гриферов.
- **Ничего не покупается.** Никакого доната за преимущества.

## Играй, а не плати
