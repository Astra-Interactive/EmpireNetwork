# Чат и почта

## Два чата

**Локальный чат** — по умолчанию. Тебя слышат игроки в радиусе 100 блоков. Сообщения помечены буквой **L**.

**Глобальный чат** — слышит весь сервер. Поставь `!` в начале сообщения. Помечены буквой **G**.

```
!Всем привет, я новенький
```

## Личные сообщения

- `/msg НИК сообщение` — написать игроку.
- `/reply сообщение` — ответить тому, кто писал тебе последним.

Кликни по нику в чате — команда `/msg` подставится сама.

## Упоминания

Напиши `@Ник` — игрок получит уведомление на экран и звук. Не злоупотребляй.

## Смайлы и ссылки

Ссылки в чате кликабельны.

Слова в фигурных скобках превращаются в смайлы: `{happy}` → `:)`, `{sad}` → `:(`, `{love}` → `<3`, `{laugh}` → `:D`.

## Чат связан с Discord и Telegram

Чат игры виден в Discord и Telegram. И наоборот. Сообщения оттуда помечены `[DS]` и `[TG]`.

## Почта

На сервере есть почтовые ящики. Это бочки с табличкой. Их ставит администрация.

- **Получить свой ящик.** Найди свободный ящик, посмотри на него и введи `/postoffice claim`. Теперь он твой.
- **Отправить посылку.** Открой ящик другого игрока и положи предметы. Забрать их может только хозяин.
- **Получить посылку.** Когда тебе что-то положили, на табличке появится отметка. При входе в игру придёт сообщение.

Так можно передавать вещи игрокам, которые сейчас офлайн.
